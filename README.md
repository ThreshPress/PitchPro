# Pitch Pro

The public page is [threshpress.github.io/PitchPro](https://threshpress.github.io/PitchPro/).

GitHub Pages is set to publish the `main` branch. `npm run build:pages` writes a static site to `dist-pages`. The workflow copies that into `docs/` and adds a root `index.html` that opens it. Players and logs stay in the browser.
